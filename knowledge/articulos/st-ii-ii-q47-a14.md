# Respondeo (excerpt)

I answer that, The virtues must needs be connected together, so that whoever has one has all, as stated above (I-II:65:1). Now whoever has grace has charity, so that he must needs have all the other virtues, and hence, since prudence is a virtue, as shown above (Article 4), he must, of necessity, have prudence also.[^newadvent]
