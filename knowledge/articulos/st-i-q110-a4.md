# Respondeo (excerpt)

I answer that, A miracle properly so called is when something is done outside the order of nature. But it is not enough for a miracle if something is done outside the order of any particular nature; for otherwise anyone would perform a miracle by throwing a stone upwards, as such a thing is outside the order of the stone's nature. So for a miracle is required that it be against the order of the whole created nature. But God alone can do this, because, whatever an angel or any other creature does by its own power, is according to the order of created nature; and thus it is not a miracle. Hence God alone can work miracles.[^newadvent]
