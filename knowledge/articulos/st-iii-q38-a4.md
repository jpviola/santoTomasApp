# Respondeo (excerpt)

I answer that, For two reasons it behooved others besides Christ to be baptized with the baptism of John. First, as Augustine says (Super Joan., Tract. iv, v), "if Christ alone had been baptized with the baptism of John, some would have said that John's baptism, with which Christ was baptized, was more excellent than that of Christ, with which others are baptized." Secondly, because, as above stated, it behooved others to be prepared by John's baptism for the baptism of Christ.[^newadvent]
