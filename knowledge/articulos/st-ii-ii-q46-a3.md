# Respondeo (excerpt)

I answer that, As already stated (Article 2), folly, in so far as it is a sin, is caused by the spiritual sense being dulled, so as to be incapable of judging spiritual things. Now man's sense is plunged into earthly things chiefly by lust, which is about the greatest of pleasures; and these absorb the mind more than any others. Therefore the folly which is a sin, arises chiefly from lust.[^newadvent]
