# Respondeo (excerpt)

I answer that, Some things there are which act, not from any previous judgment, but, as it were, moved and made to act by others; just as the arrow is directed to the target by the archer. Others act from some kind of judgment; but not from free-will, such as irrational animals; for the sheep flies from the wolf by a kind of judgment whereby it esteems it to be hurtful to itself: such a judgment is not a free one, but implanted by nature. Only an agent endowed with an intellect can act with a judgment which is free, in so far as it apprehends the common note of goodness; from which it can judge this or the other thing to be good. Consequently, wherever there is intellect, there is free-will. It is therefore manifest that just as there is intellect, so is there free-will in the angels, and in a higher degree of perfection than in man.[^newadvent]
