# Respondeo (excerpt)

I answer that, All science is derived from self-evident and therefore "seen" principles; wherefore all objects of science must needs be, in a fashion, seen. Now as stated above (Article 4), it is impossible that one and the same thing should be believed and seen by the same person. Hence it is equally impossible for one and the same thing to be an object of science and of belief for the same person. It may happen, however, that a thing which is an object of vision or science for one, is believed by another: since we hope to see some day what we now believe about the Trinity, according to 1 Corinthians 13:12: "We see now through a glass in a dark manner; but then face to face": which vision the angels possess already; so that what we believe, they see. On like manner it may happen that what is an object of vision or scientific knowledge for one man, even in the state of a wayfarer, is, for another man, an object of faith, because he does not know it by demonstration.
